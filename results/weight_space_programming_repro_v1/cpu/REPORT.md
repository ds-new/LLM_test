## 差异解释与审计

- **采样波动：**相同模型与设置不保证生成完全相同的答案或权重编辑；语料猜测和策略构造都可能对生成随机性敏感。
- **运行次数：**实验 3 各条件记录了不同的 `runs`，但 JSON 未说明重试、停止及最终答案选择规则，不能将其视为独立成功率样本。
- **协议细节：**应进一步核对提示词序列化、权重呈现精度、随机种子，以及环境版本、终止条件和评估配置。这些是待排查因素，而非已证实原因。
- **审计结果：**所有提供的结果均标记为 `tool_free: true`。实验 3 各项审计均无违规、无不确定项、无标记项；实验 5 全部编辑成功，错误列表为空。该审计支持记录中的工具使用合规性，不代表已排除所有协议差异。

## 下一步

1. **重复独立生成**：优先复测实验 3 的两个语料误判条件及 Seaquest，保存每次完整输出，预先固定重试与答案选择规则。
2. **区分生成与评估波动**：对固定策略使用多组评估种子，再对多次独立生成的策略分别评估。
3. **核对评分与协议**：人工复核 Freeway、正方形及复制头提取，逐项比对原文运行配置；补充实验 4 后再评价完整复现程度。
