# 评测口径、评选集噪声、预注册的配对 bootstrap 判定、判分器审计和去污染

## 1. 两种评测

| | 评选（选最佳存盘用） | 完整评测（下结论用） |
|---|---|---|
| 什么时候 | 训练中每 4 步 | 每个阶段结束时，对"阶段终点"和"阶段内评选最佳"各做一次 |
| 题目 | 400 条：MATH-500 抽 200 题 × 1 次 + AMC23 40 题 × 2 次 + AIME24 30 × 2 + AIME25 30 × 2 | MATH-500 全部 500 题 × 1 次；AMC23 40 × 16；AIME24 30 × 16；AIME25 30 × 16；AIME 2026 29 × 16（留出） |
| 采样 | temperature 0.6、top_p 0.95 | 同左 |
| 用途 | 维护 /root/r1zero_best（只保留评选分最高的一个存盘） | 阶段结论、对外报告 |

AIME 2026 从来不参与训练、选模型和调参，只在完整评测里单独报告，用来检查是否对四个原评测集过拟合。

## 2. 评选集的噪声有多大

D 阶段四个评选点：

| step | 评选分 | MATH-500 | AMC23 | AIME24 | AIME25 |
|---|---|---|---|---|---|
| 136 | 0.660 | 0.885 | 0.725 | 0.250 | 0.233 |
| 140 | 0.650 | 0.870 | 0.750 | 0.200 | 0.233 |
| 144 | 0.630 | 0.860 | 0.688 | 0.233 | 0.183 |
| 148 | 0.6725 | 0.865 | 0.788 | 0.317 | 0.233 |

看上去 136 → 144 连降三次。按题目配对 bootstrap（300 道题，10,000 次）：136 → 144 是 −0.030，95% 区间 [−0.064, +0.003]，没有显著；四小时后 148 反弹到新高，144 → 148 是 +0.0425 [+0.010, +0.078]，136 → 148 是 +0.0125 [−0.017, +0.042]。

结论：单次采样的 400 条评选集，相邻两点差 3 个百分点仍在噪声范围内。凭一两个评选点提前停训或回滚很容易误判；评选只用来挑存盘，结论只看完整评测。

## 3. 事先定好的判定标准

每个阶段开始前就写进 ma/stage_watch.py 的文档字符串，阶段结束后自动执行，不看结果再改：

- **主比较**：阶段终点 vs 阶段起点（都是固定步数，不涉及挑选）。阶段内评选最佳只作参考（有挑选偏差）。
- **主指标**：MATH-500 / AMC23 / AIME24 / AIME25 四个评测集**等权平均**的差值。
- **区间**：按题目配对 bootstrap 10,000 次（每个评测集内部按题重抽样，AMC/AIME 每题先对 16 次采样取平均），取 95% 区间。
- **判定**：区间下限 > 0 为"显著提升"，上限 < 0 为"显著下降"，否则"无显著差异"。
- **接续规则**：B 显著提升 → C 保留动态采样；C、D 之后的去向也事先写在 NEXT 表里。

各阶段结果：

| 比较 | 四集平均差（百分点） | 95% 区间 | 判定 | AIME 2026 |
|---|---|---|---|---|
| A：76 → 96（每批更新 8 次） | −0.32 | [−1.84, +1.14] | 无显著差异 | +1.1 [−0.9, +3.9] |
| B：96 → 116（动态采样） | +1.70 | [+0.09, +3.32] | 显著提升 | +3.0 [+0.2, +6.2] |
| C：116 → 136（学习率 2e-6） | +1.15 | [−0.42, +2.75] | 无显著差异 | +1.5 [−2.8, +5.8] |
| D：136 → 156（边界题） | +1.89 | [+0.17, +3.74] | 显著提升 | +1.9 [−1.5, +5.4] |
| 第三轮累计：76 → 136 | +2.53 | [+0.72, +4.33] | 显著提升 | +5.6 [+1.7, +10.1] |
| 第三轮累计：76 → 156 | +4.41 | [+2.57, +6.30] | 显著提升 | +7.5 [+2.2, +13.8] |

## 4. 判分器审计（v1 → v2）

R1-Zero 的奖励只看最终答案。第二轮结束后做了一次审计（ma/audit_verifier.py）：复核 v1 判错的样本，发现几类漏判：

1. 答案行外面有 markdown/LaTeX 包装（**、\( \)、\[ \]、$、重复的 "Answer:"）；
2. "**Answer:**" 后换行再写 \boxed{…}，答案行本身是空的；
3. 最后一个 \boxed 出现在最后一个 Answer 行之后；
4. 文字答案（\text{east}、人名、ellipse）大小写不同；
5. Unicode 的 ½、π 等没有转成 LaTeX。

v2（ma/reward_v2.py）修了这些，但仍然只取一个最终答案，不会因为前文出现过正确答案就判对（防止模型押多个答案）。第二轮保持 v1 不变（不在训练中途换奖励），选最佳存盘和完整评测改用 v2；第三轮训练也用 v2。

训练后期模型逐渐不写 "Answer:" 行、改用 \boxed 收尾（从 7% 升到约 50%），v2 两种都认，所以这个格式漂移不影响分数，但部署时要知道。

## 5. 去污染

- **训练集 vs 评测集**：DAPO-Math-17k 去重后按归一化文本比对，第一轮去掉 115 道和评测题重合的题；审计时（ma/audit_contam.py）又找到 6 道，第三轮的训练集去掉。
- **蒸馏数据 vs 评测集**：OpenR1-Math 和全部 629 道评测题（含 AIME 2026）做词级 13-gram 比对（短题按完整包含），连同题面含中文的共删 482 题（sft/prep_openr1.py）。

## 6. 质量监控（ma/quality.py）

每个评选点统计：中英混杂（含中文字符）的比例、同一行重复 ≥ 5 次的比例、结尾没写 "Answer:" 的比例、平均长度、反思词（wait / hmm / let me check …）次数。纯 RL 全程没有出现中英混杂；重复行在 9–14% 之间；反思词从每条约 1.5 个增加到 13–18 个，平均长度从约 900 token 增加到约 3,000 token——这是 R1-Zero 论文里描述的"自发变长、学会反思"在 8B 模型上的重现。

## 7. pass@k：还有多少题完全做不出来

完整评测里 AMC23 和各套 AIME 每题采样 16 次，可以用无偏估计算 pass@k：一题 n = 16 次里对了 c 次，pass@k = 1 − C(n−c, k) / C(n, k)，再对题取平均（脚本 [run/passk_table.py](../run/passk_table.py)）。

| step | AIME24 pass@1 / 4 / 16 | AIME25 pass@1 / 4 / 16 | AIME 2026 pass@1 / 4 / 16 | 16 次全错的题（AIME24 / 25 / 2026） |
|---|---|---|---|---|
| 46 | 20.8 / 32.1 / 46.7 | 17.3 / 30.5 / 43.3 | 15.1 / 26.6 / 37.9 | 53% / 57% / 62% |
| 76 | 23.8 / 37.4 / 50.0 | 18.5 / 28.8 / 36.7 | 14.0 / 26.4 / 34.5 | 50% / 63% / 66% |
| 116 | 22.1 / 36.8 / 56.7 | 22.1 / 33.6 / 43.3 | 18.1 / 30.1 / 44.8 | 43% / 57% / 55% |
| 136 | 25.0 / 38.2 / 53.3 | 20.8 / 31.4 / 46.7 | 19.6 / 32.1 / 44.8 | 47% / 53% / 55% |
| 148 | 26.7 / 41.8 / 56.7 | 21.9 / 31.1 / 43.3 | 19.8 / 30.5 / 37.9 | 43% / 57% / 62% |
| 156 | 27.5 / 42.3 / 60.0 | 22.3 / 33.6 / 46.7 | 21.6 / 33.5 / 48.3 | 40% / 53% / 52% |

- pass@16 大约是 pass@1 的 2 倍：会做的题也经常做错，多数投票能补回一部分（step 156 的 AIME25 多数投票 30.0%）。
- 约一半的 AIME 题 16 次全错。训练集里同样难的题在 GRPO 里组内优势为零、拿不到梯度，这是做边界题（D）的原因，也是之后转向蒸馏 SFT（E）的原因。
- step 46 → 156，AIME24 的 pass@16 从 46.7% 升到 60.0%，AIME 2026 从 37.9% 升到 48.3%：在 k = 16 这个范围内，RL 不只是让已经会的题更稳，也多做出了几道题。每套只有 29–30 题，一道题约 3.4 个百分点，差一两道题的变化不要过度解读。
