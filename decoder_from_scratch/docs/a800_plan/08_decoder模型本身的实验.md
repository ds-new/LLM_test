# 08 掌握 decoder 模型本身：要做的实验（2026-11-18）

已排的实验（06、07 和实验室）主要回答"怎么训"：规模、超参、数据、调度、优化器。这里补上"模型本身"：每个组件为什么这样设计、训出来的模型内部学到了什么、推理时怎么工作，外加 MoE 和合成数据两个专题。

## 1. 结构消融：把每个组件换掉看看（实验室之后）

代理配置 d768_l16（约 1.25 亿参数），每组 1.25B token（约 2.5 小时），一次只改一处，用每字节 bit 数和种子噪声判断差异是否真实。

| 组件 | 对照 | 主要看 |
|---|---|---|
| 归一化位置 | Pre-LN（现在）vs Post-LN（warmup 长 / 短） | 能否训动、需要多长 warmup、逐层梯度范数 |
| 归一化类型 | RMSNorm vs LayerNorm | 差别多半在噪声内，练习"不显著"的结论 |
| 位置编码 | RoPE vs 可学习绝对位置 vs ALiBi vs 不加（NoPE） | 1024 以内的 loss，以及直接拿到 2048/4096 上的外推 |
| MLP | SwiGLU vs GELU（同参数量） | 门控的收益 |
| 注意力头 | GQA（4 组 KV）vs MHA vs MQA | loss 与 KV cache 大小的取舍 |
| 词嵌入 | 输入输出共享 vs 不共享 | 小模型为什么常共享 |
| 初始化 | 残差输出投影按 1/√(2L) 缩小 vs 不缩小 | 残差流方差随层数的增长 |
| 训练上下文 | 1024 vs 4096（同 token 数） | 长短文本的 loss 和训练成本 |
| 稳定性 | 4–8 倍最优学习率下分别加 QK-norm、z-loss、logit soft-cap | 注意力 logit、输出 logit 的增长和发散 |

约 16 组，加上补种子共约 2 天 GPU；LabLM 加开关约 1 天代码。深窄 vs 浅宽已在 06。

## 2. 机理分析：训出来的模型里有什么（11-18 开始，用 v1 final）

- Induction head 与上下文学习：随机 token 序列重复一遍，看第二遍 loss；找出并消融这些头。出现时刻需要单独一次早期密集存检查点的短训练（1–2 小时，排进实验室队列）。
- Attention sink 与超大激活：注意力落在第一个 token 上的比例、残差流里的超大维度；滑动窗口去掉 / 保留开头 token 的对照。
- Logit lens：每层残差流直接解码，看预测在第几层成形，分来源比较。
- 逐层、逐头消融：去掉一层 / 一个子层 / 一个头的 loss 增量，看冗余。
- 线性探针：数据来源、绝对位置、两位数加法（个位 / 进位 / 十位）。
- 知识定位：事实性提示的因果追踪（残差流 / MLP / 注意力）。

## 3. MoE（实验室之后）

稠密 vs MoE（8 选 2，激活参数相同）vs 细粒度专家加共享专家；负载均衡用辅助 loss 和不用辅助 loss 的偏置法各一组。看同激活 / 同总参数下的 loss、专家负载、是否按来源分工。约 4 组、1 天 GPU，MoE 层约 1 天代码。

## 4. 合成数据的受控实验（实验室之后）

- 知识容量：合成人物传记，控制每条知识出现次数，100 万–5000 万参数小模型，测每个参数能存多少 bit；比较单一写法和多种改写对问答提取的影响。
- 多步推理：步数可控的小学数学题，看最多能解几步、错在哪一步，探针看中间量。
- 合计约 1 天 GPU。

## 5. 推理侧

- 现在做：解码策略与复读（贪心、重复惩罚、禁止重复 3-gram、温度、top-k、top-p、min-p）、重复片段的自我强化；量化（int8/4/3/2 仅权重、激活 int8、逐层 / 逐矩阵敏感度）。
- 之后做：KV cache 与吞吐（用第 1 部分的 MHA/GQA/MQA 模型，空闲 GPU 上测）、投机解码（实验室小模型当草稿模型，需保留两三个小模型权重）、长上下文 passkey 检索（路线 A 第 2 段之后）。

## 排期

- 11-18 晚：第 2 部分（除 induction head 出现时刻）和第 5 部分的解码、量化，和路线 A 训练共用 GPU。
- 实验室结束后：结构消融 → MoE → 合成数据，约 4–5 天 GPU（约 ¥600）。
- 第 5 部分其余几项跟在后面。

## 怎样算掌握

1. 能说出每个组件改动在这个规模上收益的方向和大小，以及是否超过噪声。
2. 拿到陌生检查点，能找出 induction head 和 attention sink，读懂 logit lens 的图。
3. 给定配置，能估出参数量、每 token FLOPs、KV cache 和解码吞吐，并和实测对上。
4. 能解释模型存知识的上限，以及为什么同一条知识需要多种写法。

## 结果（第 2、5 部分，11-18 21:59–22:55，v1 final）

完整报告和图：[results/a800/mech/REPORT.md](../../../results/a800/mech/REPORT.md)，代码 [decoder_from_scratch/a800/mech.py](../../a800/mech.py)。分析和路线 A 训练共用 GPU，期间训练慢了约一半，合计推迟约 25 分钟。基准核对：分析代码算出的加权验证 loss 2.288，与 v1 报告的 2.2879 一致。

- Attention sink 与超大激活：第 0–8 层几乎不看第一个 token；从第 9 层起每个头平均有 0.31–0.59 的注意力落在第一个 token 上。同一层，第 8 层 MLP 在残差流第 89 维写入约 4,600 的值（中位数 0.73），落在首 token 和 BOS/EOS 上，保持到第 38 层。只看最近 256 个 token（挤掉开头）loss +0.67；保留开头 4 个只 +0.065（StreamingLLM 现象）。
- Logit lens：预测逐层平稳成形，与最终 top-1 一致率到第 29 层才过半；代码第 21 层、数学第 24 层、英文第 26 层、中文第 32–33 层过半。
- 逐层消融：去掉第 0 层 +7.14（MLP 占 6.63）、第 8 层 +0.84（MLP 0.73，写超大激活的那层）、第 1 层 +0.59、第 39 层 +0.27，其余 +0.02–0.08。一起去掉最不重要的 4 / 8 层：+0.13 / +0.35，没有可以白送的层。
- 逐头消融：单个头都不超过 +0.01，449/640 个不到 0.001；最重要的 6 个里有 4 个属于照抄电路。
- Induction head：随机序列第二遍 loss 0.37（第一遍 12.3）。induction head 在第 9–16 层（L10H5 0.93、L13H4 0.89、L16H3 0.86），前一 token 头在第 7–8 层（L7H6 0.92、L8H10 0.85）。只去掉 2 个 induction head，第二遍 loss 回到 8.76；去掉 16 个，正常文本的长距离收益从 0.19 减半到 0.095；随机去掉同样多的头没有影响。
- 线性探针：数据来源从第 0 层 0.35 到末层 0.87（7 类）；绝对位置 R² 在词嵌入层为 0（RoPE 只给相对位置），第 10 层最高 0.73，末层 0.06。两位数加法模型只答对 3.6%，但 "=" 处进位可读 1.00、和的十位 0.77、个位 0.53：中间量部分算出却没用上。v1 基座的训练数据里没有合成算术；tokenizer 对照里加了 3% 合成算术后，v1 分词器的小模型两位数加法也是 100%，所以主要缺的是数据，逐位数字（v2）的优势在更难的题上（四位数加法 82.5% → 100%，两位乘两位 48% → 79%）。
- 因果追踪（55 条事实）：主语最后一个 token 的残差流在第 0–16 层恢复能找回 45–67%；第 24–32 层信息搬到最后一个 token（第 32 层 85%）；MLP 作用在主语位置的前几层（第 0–2 层 46%），注意力作用在最后位置的第 24–28 层（30%）。与 ROME 的图景一致。
- 解码：人类原文 4-gram 重复率 0.041、负对数似然 1.97。贪心 0.428 / 0.47（重复 10 倍、过于"确定"）；重复惩罚 1.2：0.051 / 0.91；top-p 0.9：0.050 / 1.72（最接近人类）；纯采样 T=1：0.028 / 2.31（尾部过多）。同一片段重复 6 遍，模型给各遍的平均概率 0.34 → 0.72 → 0.88 → 0.93 → 0.96 → 0.97：自我强化让贪心解码锁进循环。
- 量化：int8 权重无损；int4 分组 128 +0.062（per-channel +0.099）；int3 分组 128 +0.40；int2 失效。中文比其他来源敏感（int4 g128：+0.074 对 +0.049）。v_proj 最敏感（只量化它到 int3 +0.108，GQA 共享放大误差）；单层最敏感的是第 38、8、39 层。第 8 层 down_proj 输入的离群值是中位数的 66,600 倍，所以激活 int8 按张量 +0.109、按 token 只 +0.017。

还没做：induction head 出现时刻的短训练（需排进实验室）；第 5 部分的 KV cache 吞吐、投机解码、长上下文检索（见上文排期）。
