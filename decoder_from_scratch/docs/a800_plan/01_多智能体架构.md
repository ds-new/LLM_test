# 01 多智能体架构

## 六个智能体与职责

| 智能体 | 文件 | 职责 |
|---|---|---|
| 决策智能体 | `decision_agent.py` | 编排其余五个智能体，推进阶段，审核报告，按明确的规则做决策，并把每条决策的理由写入 `events.jsonl` |
| 数据智能体 | `data_agent.py`、`sources.py`、`cleaning.py` | 从 ModelScope 拉取 7 个数据集，流式完成"下载 → 清洗 → 去重 → 划分 train/val/test → 编码"，产出 token 分片；训练 tokenizer |
| 模型框架智能体 | `architect_agent.py` | 结构正确性自检（因果性、KV Cache）；对 3 个约 0.49B 的候选结构做吞吐基准；在吞吐不低于最快候选 85% 的候选里选层数最多的 |
| 模型训练智能体 | `trainer_agent.py` | bf16、torch.compile、fused AdamW、WSD 学习率；按来源权重混合采样；每 30 分钟保存一次完整检查点（模型、优化器、采样器、随机数状态）；监控 loss、梯度、吞吐、显存 |
| 测试评估智能体 | `eval_agent.py` | 按固定口径评测：分来源验证 loss、38 道选择题、12 个提示的生成质量（重复率） |
| **结果分析智能体（新增）** | `analyst_agent.py` | 把评估数字变成有统计依据的结论：噪声估计、趋势显著性、训练-验证差距、吞吐和梯度异常、剩余时间；训练结束后写最终分析报告和下一步建议 |

## 协作方式

智能体之间不直接修改彼此的内部状态，只通过两种渠道交换信息，而且全部落盘、可复盘：

- **消息总线** `events.jsonl`：每条消息都带发送方、接收方和类型（directive 指令 / report 报告 / decision 决策）。
- **共享黑板** `state.json`：记录当前阶段、训练计划、最近一次报告、评估历史等共享状态。所有写入都是原子落盘，进程随时被杀都能从断点恢复。

## 阶段流程

```
selftest → benchmark → sample → tokenizer → fast_tokenizer → build_data → plan
→ train（每 60 分钟一段：训练 → 评估 → 分析 → 决策）
→ final_eval（含测试集）→ weight_edit → passk_probe → token_probe → profile
→ analysis（结果分析智能体写最终报告）→ done → 守护脚本关机
```

## 训练阶段每段的循环

1. 决策智能体通知训练智能体：训练 60 分钟。
2. 训练智能体报告：步数、吞吐、loss、梯度范数、各来源已过的遍数、当前权重。
3. 决策智能体通知评估智能体：做一次评估。评估智能体报告验证 loss（分来源）、选择题准确率、生成重复率。
4. 结果分析智能体报告趋势、噪声、哪些来源显著变差、有哪些异常，以及剩余时间。
5. 决策智能体按下面的规则做决策，然后进入下一段。

## 决策规则

| # | 规则 | 触发条件 | 动作 |
|---|---|---|---|
| 1 | 稳定性 | 连续 3 步出现非有限 loss，或验证 loss 比最佳值高 5% | 回滚到上一个检查点，学习率 ×0.7 |
| 2 | 计划 | 按最近 4 段吞吐的中位数预测会超时或有富余 | 调整总步数，每次最多 8%；进入衰减阶段后不再调整；总量不超过 25B token |
| 3 | 重复 | 预测某来源到训练结束会被重复超过 4 遍 | 按比例降低该来源的权重 |
| 4 | 遗忘（已改） | 结果分析判定某来源显著变差：最近 8 次评估做回归，t ≥ 3，且拟合上升超过 3 倍单次噪声；同时总体没有变差 | 该来源权重 ×1.2，不超过初始值的 1.5 倍；同一分析窗口内不重复调整 |
| 5 | 结束 | 计划完成，或到达时间上限 | 最终评估 → 保存模型 → 各项探测 → 结果分析 → 关机 |
| 6 | 异常（新增） | 连续 4 次回滚仍不稳定，或训练中检查点丢失 | 抛出 FatalError，退出码 2，守护脚本关机 |

## 停机规则（由守护脚本 `run_loop.sh` 执行）

| 情况 | 行为 |
|---|---|
| 全部流程完成（退出码 0） | 2 分钟后关机 |
| 致命错误（退出码 2）：FatalError；同一阶段连续失败 5 次；磁盘满、GPU 或驱动类错误重启一次后仍然出现 | 写入 `FAILED.json`，2 分钟后关机 |
| 可重试错误（退出码 1） | 2 分钟后用最新代码重启，最多 20 次，超过就关机 |
| 心跳超过 45 分钟没有更新 | 判定卡死，杀掉进程后重启（计为一次失败） |
| 用户放置 `STOP` 文件 | 保存后退出，**不关机** |
| 运行目录里有 `NO_SHUTDOWN` 文件 | 任何情况下都不关机（调试用） |

## 时间上限（已修复）

训练时间上限是 192 小时，现在**按实际训练耗时计算**，停机期间不计入。之前按墙钟时间算，机器停了几天后一恢复就会被误判为超时，直接结束训练。
