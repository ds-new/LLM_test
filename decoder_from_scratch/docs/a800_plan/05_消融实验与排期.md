## 判定规则

- **"显著"的标准**：同一配置换种子重复训练得到 σ。两次训练之差超过 3·√2·σ 才算真实差异。σ 只由 3 次训练估计，只能看量级。
- **v2 是否明显更好**：对照里加权 bits/字节低 1% 以上或运算准确率高 10 个点以上，并且差异超过上面的噪声标准。
- **路线 A 的中途检查**（只在 v2 明显更好时开启）：第 1 段到 2B token 时，用 0.5B token 做一次快速退火探针。验证 loss 没有比 v1 基线（2.2879）低 0.005 以上，就停掉路线 A（检查点保留），改走路线 B：用 v2 tokenizer 从头训。

## 路线 A 的要点

- 第 1 段：从 v1 最终权重和优化器状态出发，学习率 500 步升到 2e-4 后恒定，10B token 全新数据，上下文 1024。
- 第 2 段：5B token，配比向数学、代码、教育类、合成教材倾斜，上下文 4096，学习率线性退火到 2e-5。
- 评估口径和 v1 完全一样（v1 的验证分片、1024 长度），曲线可以直接接着比。
- v1 在 4096 长度下的验证 loss 是 4.42（1024 长度是 2.29）：它没见过 1024 以外的位置，长上下文基本不可用。第 2 段结束后会再测一次。
- 第 1 段的验证 loss 会先高于 v1：v1 末尾已经退火，现在学习率重新升高。要等第 2 段退火后才能和 v1 比。
