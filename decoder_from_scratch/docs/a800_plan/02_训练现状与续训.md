# 02 训练现状与续训

## 模型

| 项目 | 数值 |
|---|---|
| 结构 | d1024_l40：40 层，hidden 1024，16 个注意力头，4 个 KV 头（GQA），SwiGLU FFN 2816，RoPE，Pre-RMSNorm |
| 参数量 | 483,738,624（约 0.48B）。输入输出共享嵌入：嵌入约 33M，Transformer 层约 451M |
| 词表 / 上下文 | 32k（自训 BBPE）/ 1024 |
| 训练配置 | 每步 524,288 token；峰值 lr 4e-4；WSD（warmup 1000 步，最后 20% 线性衰减到 0.1 倍）；AdamW β2=0.95，wd=0.1；梯度裁剪 1.0 |
| 计划 | 47,683 步，25B token（每个参数约 52 个 token） |

## 第 40,539 步时的效果（21.25B token）

| 来源 | 验证 loss | 困惑度 | bits/字符 | 已过遍数 |
|---|---|---|---|---|
| zh_cci3 | 3.197 | 24.5 | 2.92 | 1.53 |
| zh_fwedu | 3.184 | 24.1 | 2.75 | 1.72 |
| zh_industry | 3.026 | 20.6 | 2.74 | 1.72 |
| en_fwedu | 1.711 | 5.5 | 1.00 | 1.87 |
| en_cosmo | 1.171 | 3.2 | 0.62 | 1.58 |
| code | 1.155 | 3.2 | 0.62 | 1.66 |
| math | 1.445 | 4.2 | 0.94 | 1.41 |
| **加权总体** | **2.379** | **10.8** | | |

- 中文 loss 高主要是分词粒度造成的：按字节折算，中英文的信息量基本持平（约 0.9–1.0 bits/字节）。
- 恒定学习率阶段的最后一段，每 1B token 只降 0.0065；衰减开始后 2.4k 步就降了 0.024。剩余的衰减阶段收益最大，按趋势粗估最终验证 loss 在 2.32–2.35（未验证）。
- 训练过程稳定：梯度范数 0.15–0.2，没有尖峰，也没有 NaN；吞吐约 46k tok/s，MFU 约 50%。
- 生成的语言流畅，但事实经常编造；贪心解码的 4-gram 重复率约 0.4。这是 0.5B 基座模型的典型表现。

## 中断与续训经过

1. **11-08 13:29 停机**：守护日志里没有任何退出记录，说明是实例被外部停机，不是代码崩溃。检查点 `latest.pt` / `prev.pt` 完好（在系统盘 `/root/a800_scratch/checkpoints/`，含优化器状态）。
2. **第一次重启失败**：误用了 miniconda 基础环境，它的 torch 2.9 目录里残留了旧版 `kernel/flex_attention.py` 等文件，导致 torch.compile 报 `duplicate template name`。已改回原来的 `/root/a800_venv`，基础环境恢复原样。
3. **第二次启动被判定超时**：时间上限按墙钟时间算，停机的 6 天被计入，系统直接跳到了最终评估。当时 `NO_SHUTDOWN` 还在，没有误关机。已改成按实际训练耗时计算，并把状态回滚到 train。
4. **第三次正常续训**：第 40,560、40,580 步的 loss（2.2074、2.2404）与中断前逐步一致，说明是精确恢复；吞吐约 46.5k tok/s。时间上限还剩约 59 小时额度。

> 注意：第 2 步误触发时生成了一份第 40,539 步的 `model/final.pt`，训练结束时会被覆盖。`eval_history.jsonl` 里第 40,539 步有重复记录，结果分析智能体按步数去重，不受影响。

## 监控与操作（在服务器终端执行）

```bash
cd /root/autodl-tmp/verl_megatron_sglang
PY=/root/a800_venv/bin/python

# 查看进度和最近的智能体消息
$PY -m decoder_from_scratch.a800.loop status

# 最近的训练日志、分析结论
tail -n 3 /root/autodl-tmp/a800_pretrain_v1/train_log.jsonl

# 停止：当前步完成后保存并退出，不关机
$PY -m decoder_from_scratch.a800.loop stop

# 用最新代码重启（保存后由守护脚本重启）
$PY -m decoder_from_scratch.a800.loop restart

# 禁止自动关机 / 恢复自动关机
touch /root/autodl-tmp/a800_pretrain_v1/NO_SHUTDOWN
rm /root/autodl-tmp/a800_pretrain_v1/NO_SHUTDOWN

# 守护脚本被关掉后手动启动（必须用 venv）
env -u OMP_NUM_THREADS PYTHON=$PY setsid nohup bash decoder_from_scratch/a800/run_loop.sh >/dev/null 2>&1 < /dev/null &
```
